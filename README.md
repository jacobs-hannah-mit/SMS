Running splice modifier score (SMS)

This repo contains code used to run SMS GLM with GTEx variants.  

The scores are generated by intersecting variants with various annotations of interest and calculating distance to nearest splice sites. Currently we do not have functionality to quickly annotate your own set of variants. 

Dependencies: jupyter notebook, python, pip

# How to download SMS and run GLM (with conda):

conda create -n SMS_env

conda activate SMS_env

git clone https://github.com/jacobs-hannah-mit/SMS.git

pip install -e . #need pip installed

pip install zenodo-get #to fetch zenodo files 

zenodo_get 15790343

# Non-command line downloading
